# Literature Organizer (文献系统梳理)

将指定目录下的学术论文PDF批量处理，提取结构化信息并生成格式化Markdown文件。

## 工作流程


### 第一步：确认目录

询问用户要处理的目录（如果用户未指定）。默认使用当前工作目录。
用 Glob 扫描目录下所有 `*.pdf` 和`*.md` ，列出找到的论文清单给用户确认。

### 第二步：逐篇提取论文文本

对每篇PDF，使用内置 `pdf` skill 提取全文文本（若没有，询问用户是否需要安装）。

1. 调用 `Skill: pdf` 加载 PDF 处理能力
2. 对于每篇论文 PDF，使用 pdf skill 的文本提取功能获取全文：
   - **常规文本型 PDF**：使用 pypdf `extract_text()` 快速提取
   - **多栏排版 PDF**：使用 pdfplumber 保留布局
   - **扫描版/图片型 PDF**：使用 OCR（pytesseract + pdf2image）回退
3. **文本量控制**：如果文本量很大（超过上下文窗口），优先读取前3页（标题、作者、摘要、引言）和后2页（结论）；短论文（<10页）全部读取


### 第三步：提取并组织信息

对每篇论文，从文本中提取以下字段。**必须以论文原文内容为准，不要编造信息。**

| 列名 | 说明 | 提取方法 |
|------|------|----------|
| 题名 | 论文完整标题 | 从论文第一页标题区域提取 |
| 作者 | 所有作者姓名 | 从作者列表提取，多个作者用分号分隔 |
| 发表时间 | 发表/接收/在线日期 | 从 Received/Published/Accepted 字段提取，优先使用 Published 日期 |
| 文献来源 | 期刊/会议名称 | 从期刊名/会议名提取，通常出现在页眉或首页 | DOI(可一键跳转) |
| 关键词 | 论文关键词（中文） | 从 Keywords 字段提取并翻译为中文，多个关键词用分号分隔 |
| 摘要 | 论文摘要（中文） | 从 Abstract 区域完整提取并翻译为中文 |
| 研究内容和方法 | 论文做了什么、怎么做的 | 从 Introduction 和 Methods 概括，2-5句话，中文 |
| 研究思路 | 论文的技术路线和逻辑 | 总结论文的研究框架、核心思路和技术路径，2-4句话，中文 |
| 实现效果 | 论文实验结果的具体性能指标数据（文中重点关注的数据均要涉及） | 与之前研究比较的优缺点 | 

### 第四步：生成Markdown文件

将所有论文信息用 `Write` 工具直接写入 Markdown 文件。

**输出文件**：`文献梳理报告.md`（默认放在论文所在目录）

**Markdown 模板**：

```markdown
# 文献梳理报告

> 📅 生成时间：YYYY-MM-DD | 📄 共计 N 篇论文

---

## 1. 论文完整题名

| 字段 | 内容 |
|------|------|
| **题名** | ... |
| **作者** | ... |
| **发表时间** | ... |
| **文献来源** | 期刊/会议名 [[DOI](https://doi.org/...)] |
| **关键词** | ...（中文，分号分隔） |
| **摘要** | ...（中文翻译） |
| **研究内容和方法** | ... |
| **研究思路** | ... |
| **实现效果** | ... |

---

## 2. 第二篇论文题名

| 字段 | 内容 |
|------|------|
| ... | ... |
```

**注意事项**：
- 每篇论文一个 `##` 二级标题和一张字段表格
- 文献来源行必须包含 DOI 超链接：`期刊名 [[DOI](https://doi.org/...)]`
- 内容较长的字段（摘要、研究内容和方法、研究思路、实现效果）可以用多行文字
- 如果某字段在论文中找不到，填写"未提取到"

### 第五步：报告结果

生成 Markdown 后，向用户汇报：
- 处理的论文数量
- 输出文件路径
- 简要列出每篇论文的题名和核心发现
- 如果某篇论文某些字段无法提取，如实告知 

## 注意事项

- **不要编造**：所有提取信息以原文为依据。如果某字段在论文中找不到，填写"未提取到"
- **"研究内容和方法"与"研究思路"的区别**："研究内容和方法"偏重具体做了什么实验/仿真/设计；"研究思路"偏重为什么这么做、背后的逻辑链条
- **进度汇报**：处理每篇论文前，先告诉用户正在处理哪篇，让用户了解进度
- **环境配置**：该skill需要python环境进行pdf的处理，若用户未拥有python环境，则询问用户是否需要安装，并自动配置好调用该skill所需的环境
